# Student Management System

A simple command-line Student Management System built with **TypeScript** and **Node.js**.

The program allows users to manage student information through a terminal-based menu.

## Features

- Add a new student
- View all students
- Find a student by ID
- Update student information
- Delete a student
- Search students
- Filter students by course
- Filter students by Pass/Fail result
- Display student statistics
- Sort students by name
- Sort students by marks
- Input validation
- Duplicate email checking

## Technologies Used

- Node.js
- TypeScript
- npm
- Git / GitHub
